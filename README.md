# Lab 01 – Network Implementation

## Overview
Implemented a network topology using **Mininet**, including a learning switch and a router to demonstrate Software-Defined Networking (SDN) concepts.

## Features
- **Network Topology:** Created and configured the required network in Mininet.
- **Learning Switch:** Implemented MAC address learning, packet forwarding, and flow rules.
- **Router:** Implemented IP routing, ARP handling, packet header updates, and packet-blocking logic.

## Technologies
- Python
- Mininet
- OpenFlow / SDN

## Learning Outcomes
Gained practical experience in network topology construction, packet forwarding, MAC learning, ARP resolution, and IP routing.
